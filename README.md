# YouTube Desktop for iOS

一个基于 `WKWebView` 的 iPhone YouTube 桌面版封装项目。

## 当前已验证功能

- YouTube 桌面版页面
- 视频页移动端布局适配
- 后台音频播放
- 锁屏 / 灵动岛媒体状态
- 画中画（PiP）
- iOS 原生全屏播放
- 系统媒体播放 / 暂停命令桥接
- 自定义 App 图标

## 当前实验功能

- 自动处理 YouTube 可跳过广告：仍在实验和真机验证阶段，当前版本尚未形成稳定方案。

## 开发环境

- Xcode 16.4
- iOS Deployment Target 17.0
- Swift / UIKit / WebKit
